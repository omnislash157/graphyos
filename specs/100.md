# showcase takes the flags its own refusal names, so a monorepo showcases from where the user stands
issue: graphyos #100
host: linux
scars: S1 S8 S2 S3 S4 S6

## Contract
- C1 `graphy showcase <repo> --package <name> --site-packages <dir>` hands both to eat; a three-package repo showcases the named one
- C2 `graphy showcase <repo>` bare over a three-package repo refuses in showcase's own words, naming the showcase line with both flags, exit 2
- C3 the flags the refusal names are flags `graphy showcase --help` lists; `--no-provision` beside `--site-packages` is refused by name
- C4 three runs of one showcase answer the same text: the second and third read the eat the first landed

- IN: engine/graphy/showcase.py
- IN: engine/graphy/cli.py
- IN: CLAUDE.md
- OUT: engine/graphy/eat.py
