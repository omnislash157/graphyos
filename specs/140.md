# pillars, arms and draw count the dependencies the store declares, never a constant of their own
issue: graphyos #140
host: linux
scars: S1 S8 S4 S6 S7

## Contract
- C1 `pillars.relations_for` and `arms.fanin_relations_for` read the store's declared DEPENDS family, the set `blast` walks
- C2 a store that declares nothing cuts, crowns and draws over the old constants, byte for byte
- C3 `draw` weighs units, pillars and an arm over `pillars.relations_for`, the matrix `pillars` prints
- C4 `graphy pillars` names in its header the relations it counted, never a fixed list
- C5 a module node crowns only an arm where nothing else is depended on
- C6 on the graphy tenant the proposal, the SEAM crown and docs/pillars.svg move and are recorded before and after
- C7 fastapi, sqlalchemy and hono arm regions render the same under both readers; express's module crowns are named
