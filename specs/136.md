# a cp1252 stdin reads the utf-8 a client wrote: the MCP face, the gate and the hooks
issue: graphyos #136
host: linux, windows
scars: S1 S8 S2 S3

## Contract
- C1 every entry point that calls `utf8_streams()` reconfigures a stdin that cannot carry the glyphs to utf-8 before the first read
- C2 `graphy mcp` over a cp1252 stdin answers about the symbol the client sent, never its mojibake
- C3 the gate over a cp1252 stdin blocks an unwalked edit to a file under a non-ASCII path
- C4 the capture hook over a cp1252 stdin writes the tail of a transcript under a non-ASCII path
- C5 the Windows job runs the cp1252 stdin tests on the tree that lands
- C6 the installed end hook, run through the shell its harness uses, captures under a cp1252 stdin a tail with no CR
