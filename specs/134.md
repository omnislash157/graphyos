# the MCP server holds no store between calls, so a rebuild under a live server lands on Windows
issue: graphyos #134
host: linux, windows
scars: S1 S8 S3 S7

## Contract
- C1 between two tool calls a live `graphy mcp` holds no sqlite connection
- C2 each tool call opens what `graphy <verb> --tenant` opens now, answers, and closes it, on success and on refusal
- C3 `graphy build` replaces the store while a server is alive, and the next call answers from the landed store
- C4 a stale store refuses the call in the CLI's words and the next call after the rebuild answers
- C5 the Windows job runs the rebuild-under-a-live-server test the #134 deselect skipped
