## Contract
- C1 `graphy build` with no input moved writes nothing and says `store fresh, 0 lanes recompiled`
- C2 a few moved lanes are rewritten in place in one transaction, equal to a full compile: every table, the generation, the counts
- C3 an edge of another lane that resolves through a moved lane is re-admitted, and an id two lanes carry changes owner exactly as a full compile decides
- C4 a format-4 store still answers every door; the next build compiles format 5 whole, and every build after updates in place
- C5 `--container all` re-emits only the containers whose shard bytes moved
- C6 a door reading the store while an update lands answers from the store before or after, never an error
