## Contract
- C1 a stored blast or descend lands every neighbour row of each node it expanded and each owner it looked up, keyed by generation, door, seed and depth
- C2 a repeat re-runs the live door rules over the recorded facts with zero store reads and renders byte-identically to the live door
- C3 a relation re-declared over the same generation answers what the live door answers, from facts or live where a node was never read
- C4 door rules changed in the engine, over stored facts, answer what the changed live door answers, with no source pin in any key
- C5 `SOURCE_SHA`, `rules_digest`, `vocabulary`, `RULE_ROOTS`, `RULE_MODULES`, `RULE_EXEMPT` and review.py's `cache-key-closure` are gone
- C6 recall by seed or by target re-derives each stored door's answer from its facts under the live rules, zero store reads
- C7 the FastAPI repeat seconds and stored bytes are measured before and after, and `measure.py diff` names no regression
- C8 a door stored by the 0.2.6 layout is never read as facts: the repeat runs live and records beside it
