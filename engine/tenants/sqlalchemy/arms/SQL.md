# SQL — the expression floor (`sqlalchemy.sql` · `schema` · `types` · `inspection`)

> Load before touching a SELECT construct, a column expression, a type, `MetaData`/`Table`/`Column`,
> or `inspect()`. By fan-in this is the most depended-on unit in the package: every other pillar
> calls in. Hand-cut from the walk's evidence; the generated region at the bottom is the walk's own inventory and the re-walk.

## ⚖ The law of this arm
`sql` is the floor the walk names: the greatest fan-in no arm owns. `_selectable_constructors.select`
is the single most-called symbol across the pillars; `coercions.expect` is the one door a Python
value passes through to become an expression; `inspection.inspect` is the one door from an object
to its inspection target, and the ORM, the dialects and the testing harness all knock on it.

## The load-bearing symbols (walk-derived)
**`sql`** — `_selectable_constructors.select` · `coercions.expect` · `_elements_constructors.bindparam`
/ `text` · `elements.literal` / `literal_column` / `BindParameter` / `quoted_name` ·
`sqltypes.String` / `Numeric` · `type_api.to_instance`.
**`schema`** (re-exported by `sql.schema`) — `MetaData` · `Column` · `Table`.
**`inspection`** — `inspect`.

## Cross-pillar joins (all inbound)
- ← **ORM**, **DIALECTS**, **TESTING** call `select`, `inspect`, `expect`, `bindparam`, `literal_column`.
- ← **DIALECTS** own the type subclasses (`String`, `Numeric`, `to_instance`).

## The join out
typing_extensions — `Protocol`, `TypedDict`, `Self` under the expression classes.
